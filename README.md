# Gestão de Pedidos

Projeto de estudo desenvolvido utilizando:

- .NET
- ASP.NET Core
- Entity Framework Core
- SQL Server
- React

## Estrutura

- `backend/` - API ASP.NET Core
- `frontend/` - aplicação React

## Backend

API responsável pelo gerenciamento de:

- Clientes
- Produtos
- Pedidos
- Itens dos pedidos
